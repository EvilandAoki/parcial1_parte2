# Parcial 1 - Parte 2 (Videojuegos)

Proyecto de Unity con una esfera texturizada con un mapa normal, una luz puntual y color rojo.

## Requisitos

- Unity **6000.3.26f1** (Unity 6, URP)
- GIMP (para generar el mapa normal)

## Actividad

1. Agregar una esfera a la escena.
2. Crear un material con un mapa normal (hecho en GIMP) que contenga el nombre del autor.
3. Agregar un Point Light de cualquier color junto a la esfera.
4. Colorear la esfera de rojo.

## Historial de commits

| # | Commit | Descripción |
|---|--------|-------------|
| 1 | creando esfera | Esfera 3D en la escena |
| 2 | texturizando esfera | Material con mapa normal |
| 3 | agregando luz | Point Light junto a la esfera |
| 4 | coloreando esfera de rojo | Color base rojo en el material |

## Cómo abrir el proyecto

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/EvilandAoki/Parcial_1_parte_2.git
   ```
2. Abrir la carpeta desde Unity Hub (**Add → Add project from disk**) con la versión indicada.
3. Abrir la escena en `Assets/Scenes/`.
